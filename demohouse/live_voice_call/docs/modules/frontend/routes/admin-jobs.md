# frontend/src/routes/admin-jobs.tsx

## 模块职责

岗位管理后台页面，提供岗位列表、搜索、创建（CSV 上传）、详情查看和删除。

## 路由与鉴权

- 路由：`/admin/jobs`
- 需管理员登录（`useAdminAuth`）
- 在 `AdminShell` 中渲染

## CSV v2 前端规则

### 固定表头

前端常量 `CSV_TEMPLATE_COLUMNS` 固定为：

```text
场景,问题,评分标准,最大分数
```

上传前会先做首行表头校验，不匹配直接阻止提交。

### 上传提示文案（与后端一致）

创建岗位弹窗内提示：
- 场景首问必须填写 `评分标准/最大分数`
- 同场景子问这两列必须留空
- 空值语义是“子问分段”，不是字段继承

### 最小可用示例

```csv
场景,问题,评分标准,最大分数
项目复盘场景,请先介绍项目目标与背景,关注目标/约束/结果是否完整且可追问,5
,你在这个项目里承担了什么关键职责,,
,项目最终结果如何，有哪些可量化指标,,
线上故障场景,描述一次线上故障处理（发现-定位-止血-复盘）,关注排障路径与优先级判断,5
,如果同类故障再次发生你会如何机制化避免,,
```

模板文件：`demo_resource/question_bank_v2_template.csv`。

## 创建岗位流程

```typescript
1. 校验必填字段（岗位信息 + CSV 文件）
2. 读取 CSV 首行并校验表头
3. 组装 FormData（name/duties/requirements/notes/question_bank）
4. 调用 POST /api/admin/jobs
5. 成功后重置表单并刷新列表
```

## 岗位详情页字段（v2 语义）

题库表格按以下列展示：
- `场景`
- `类型`（由 `score_format` 推导）
- `题目`
- `评分标准`
- `最大分数`

类型判定规则：
- `score_format` 非空：`场景首问`
- `score_format` 为空：`场景子问`

## 与后端契约对齐

前端仅做表头校验；行级强校验由后端执行。常见 400 错误会直接透传到页面顶部。

评分语义提示：
- 面试过程按子问逐条进行。
- 最终评分按“场景连续段”聚合，一段一次评分。
- 评分返回结构固定为 `numeric_score + comment`。

高频错误：
- `CSV 第N行“场景”为空，且前面没有可延续的场景`
- `CSV 第N行“评分标准”不能为空（场景首问必填）`
- `CSV 第N行“最大分数”不能为空（场景首问必填）`
- `CSV 第N行“评分标准”必须留空（场景子问不允许填写）`
- `CSV 第N行“最大分数”必须留空（场景子问不允许填写）`

## 手工验证建议

1. 上传 `question_bank_v2_template.csv`，应创建成功。
2. 把首行 `场景` 清空，应收到“无法延续场景”错误。
3. 删除某场景首问的 `最大分数`，应收到“场景首问必填”错误。
4. 在子问行填入 `评分标准`，应收到“子问不允许填写”错误。
5. 查看岗位详情，确认题库列显示为 `场景/类型/题目/评分标准/最大分数`。
